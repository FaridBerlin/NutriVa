# NutriVa Project Description

NutriVa is a full-stack nutrition and wellness application built with React, Vite, Node.js, Express, and MongoDB. Users can create health profiles, calculate nutrition targets, generate personalized meal plans, track completed meals, view progress, and use an AI assistant for nutrition-related questions.

The frontend provides the responsive user interface, protected routes, dashboards, forms, charts, animations, and shared application state. The backend exposes authenticated REST APIs for users, profiles, meal plans, diet tracking, and AI chat. JWT authentication, Mongoose models, email-based password recovery, and Ollama integration support the main application workflows.
